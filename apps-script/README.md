# ติดตั้ง Apps Script สำหรับระบบจองห้อง

## 1. เปิด Apps Script

1. ลงชื่อเข้าใช้ Google ด้วยบัญชีเจ้าของ Sheet แล้วเปิด Google Sheet `Booking_Room`
2. เลือก **ส่วนขยาย > Apps Script** (เมนูนี้จะไม่เปิดให้แก้ไขหากยังไม่ได้ลงชื่อเข้าใช้)
3. ลบโค้ดเดิมในไฟล์ `Code.gs`
4. คัดลอกโค้ดจากไฟล์ `Code.gs` ที่เตรียมไว้ไปวาง แล้วกดบันทึก

โค้ดตั้งค่า Spreadsheet ID และชื่อแท็บ `room` กับ `bookings` ให้ตรงกับไฟล์นี้แล้ว

## 2. ตั้งเขตเวลา

1. ใน Apps Script เปิด **การตั้งค่าโปรเจกต์**
2. ตั้งเขตเวลาเป็น **(GMT+07:00) Bangkok**

## 3. ตั้งรหัสสำหรับหน้าแอดมิน

1. ใน **การตั้งค่าโปรเจกต์** ไปที่ **พร็อพเพอร์ตี้สคริปต์**
2. เพิ่มพร็อพเพอร์ตี้ชื่อ `ADMIN_KEY`
3. ตั้งค่าเป็นข้อความลับที่คาดเดายาก

รหัสนี้ต้องเก็บไว้ในตัวแปรฝั่งเซิร์ฟเวอร์ของ Next.js ห้ามใช้ชื่อที่ขึ้นต้นด้วย `NEXT_PUBLIC_`

## 4. Deploy เป็น Web App

1. กด **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้**
2. กดแก้ไขการทำให้ใช้งานได้เดิม แล้วเลือก **เวอร์ชันใหม่**
3. ตั้ง **ดำเนินการในชื่อ** เป็นตัวคุณ
4. ตั้ง **ผู้ที่มีสิทธิ์เข้าถึง** เป็นทุกคน หากเว็บไซต์ต้องให้ผู้ใช้ทั่วไปจองได้
5. กด **ทำให้ใช้งานได้** และอนุญาตสิทธิ์ให้สคริปต์หากมีหน้าถาม
6. URL ที่ลงท้ายด้วย `/exec` เดิมยังใช้ได้

เมื่อมีการจองใหม่ ระบบจะเพิ่มคอลัมน์ `status_reason`, `updated_at`, `updated_by` ในแท็บ `bookings` และสร้างแท็บ `audit_log` ให้อัตโนมัติ ไม่ต้องเพิ่มด้วยตนเอง

## 5. ทดสอบอ่านรายชื่อห้อง

เปิด URL นี้ในเบราว์เซอร์ โดยเปลี่ยนส่วนแรกเป็น Web App URL ของคุณ:

```text
WEB_APP_URL?action=getRooms
```

ถ้าทำงานถูกต้อง จะได้ JSON ที่มีห้อง 704, 706, 707, 708, 709, 801, 806 และ 807

## 6. การทำงานหลังอัปเดต

Next.js ต้องส่งคำขอ POST จากฝั่งเซิร์ฟเวอร์ไปยัง Web App URL:

```json
{
  "action": "createBooking",
  "data": {
    "room": "704",
    "booking_date": "2026-09-10",
    "start_time": "09:00",
    "end_time": "11:00",
    "name": "สมชาย ใจดี",
    "student_id": "65000001",
    "purpose": "ประชุมงานกลุ่ม"
  }
}
```

ระบบจะตรวจห้อง ตรวจข้อมูล ตรวจเวลาสิ้นสุด กันการจองซ้อน และจำกัดการส่งซ้ำ ก่อนบันทึกลงแท็บ `bookings`

การอ่านรายการทั้งหมดและการเปลี่ยนสถานะต้องมี `ADMIN_KEY` ที่ตรงกัน ผู้จองตรวจสอบหรือยกเลิกรายการของตนได้ด้วยรหัสการจองและรหัสนักศึกษา
